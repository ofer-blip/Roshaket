# עוזר משימות תואר שני (Academic Task Assistant)
מערכת ניהול משימות ולוח זמנים מותאמת אישית ללימודי תואר שני בחינוך וחדשנות פדגוגית (מכללת בית ברל - תוכנית המהפכה).

## מאפיינים עיקריים
- **תמונת סמסטר מלאה:** ריכוז כרונולוגי של שלושת קורסי הליבה (הערכת תוכניות – מור, פיתוח חדשנות – ואסל, סוגיות בהערכה – לוי-ורד).
- **התאמה מלאה למובייל (PWA):** מותאם למסכי מגע עם אפשרות התקנה למסך הבית (Add to Home Screen).
- **סנכרון חכם ליומן (Google Calendar):** ייצוא קובץ `.ics` מאוחד או 3 יומנים מופרדים בצבעים שונים לכל מרצה.
- **מעקב ביצוע שוטף:** שמירת סטטוס מטלות בזיכרון המקומי ומעקב התקדמות באחוזים.

## פריסה (Deployment)
הפרויקט מוגדר לפריסה על גבי Firebase Hosting תחת פרויקט `d-dialog-hub`.
```bash
firebase deploy --only hosting
```
